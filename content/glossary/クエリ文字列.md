## 一言でいうと

ウェブサイトのURLの最後に付く「?」の後ろの部分で、検索条件や情報を送るための仕組みです。

## もう少し詳しく

クエリ文字列とは、インターネットのアドレス（URL）に付け足される検索や指定の情報のことです。

具体例を挙げると、Amazonで「パソコン」を検索したとき、URLが次のようになります：

```
https://www.amazon.co.jp/s?k=パソコン
```

この「?k=パソコン」の部分がクエリ文字列です。「？」の後ろに「k=パソコン」という情報が付いています。これは「kという項目（キーワード）でパソコンを検索して」という意味を表しています。

別の例として、天気予報サイトで「東京の天気」を見たいなら：

```
https://weather.example.com/forecast?city=tokyo
```

こちらは「cityという場所を東京に指定して」という意味です。

複数の条件を指定する場合は「&」でつなぎます：

```
https://shop.example.com/products?category=shoes&price=5000
```

これは「カテゴリを靴にして、価格を5000円にして」という複数の指定を同時に送っています。

## よく使われる場面

エラーログサイトでは、ユーザーが検索したい条件をクエリ文字列で指定します。例えば：

```
https://logs.example.com/errors?level=ERROR&date=2024-01-15
```

このように「レベルをERRORに、日付を2024年1月15日に」という指定ができます。

## 関連する言葉

- **URL**：ウェブサイトのアドレス全体
- **パラメータ**：クエリ文字列の「k=」や「city=」など、個別の指定項目
- **キーと値**：「k=パソコン」の「k」がキー、「パソコン」が値と呼びます
