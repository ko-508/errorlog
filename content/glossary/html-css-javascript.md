## 一言でいうと

ウェブサイトを作るための３つの基本的な技術で、HTMLが骨組み、CSSが見た目、JavaScriptが動きを担当しています。

## もう少し詳しく

ウェブサイトを建物に例えるなら、HTMLは柱や壁などの骨組みです。文章や画像、ボタンなど「何を表示するか」を決めます。

CSSはその建物のペンキ塗りや内装です。HTMLで作った要素の色、大きさ、配置などを「どう見せるか」を調整します。

JavaScriptはその建物の機械装置です。ボタンを押したら何かが起こる、画面をスクロールしたらアニメーションが動くなど、「どう動くか」を制御します。

この３つが協力することで、初めて使いやすくて見た目の良いウェブサイトが完成します。

## よく使われる場面

プログラマーはエラーログを見た時、「JavaScriptでエラーが出ている」「CSSが読み込めていない」など、どの技術で問題が起きたのかを判断します。また「HTMLの構造を見直す必要がある」という判断も一般的です。

## 関連する言葉

- **フロントエンド**：ウェブサイトの表示部分を作る技術全般
- **ブラウザ**：この３つの技術を実行してウェブサイトを表示するソフト
- **コード**：プログラマーが書く指示文
- **ウェブサイト**：これらの技術で作られたページ
